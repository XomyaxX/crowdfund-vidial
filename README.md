# Примеры страниц сбора: «Суперглазка» и БФ «Видеаль»

Две статические страницы в одном репозитории. Позже их планируется разнести на отдельные домены. Сейчас это пример для GitHub Pages: студия и благотворительный фонд лежат рядом, но не смешаны.

Платежей на страницах нет. Кнопки ведут к блоку реквизитов или копируют текст письма. Везде, где данных не хватает, стоит жёлтая метка **[уточнить]**.

## Как открыть локально

Из корня репозитория:

```bash
python3 -m http.server 4173
```

Дальше в браузере:

- http://127.0.0.1:4173/
- http://127.0.0.1:4173/superglazka/
- http://127.0.0.1:4173/fond/

Сервер нужен, чтобы пути совпали с GitHub Pages. Ссылки между страницами относительные: `superglazka/`, `fond/`, из вложенных папок — `../`. Корневых путей вида `/superglazka/` нет: на Pages проект открывается не с корня домена, а из каталога репозитория.

Перед переносом на свой домен замените `canonical` и `og:url`, уберите ссылки «обе страницы» и «пример страницы в этом репозитории» (`../` и `../fond/`, `../superglazka/`) и подключите свой адрес в настройках Pages или на хостинге.

## GitHub Pages

После включения страницы будут здесь:

- https://xomyaxx.github.io/crowdfund-vidial/
- https://xomyaxx.github.io/crowdfund-vidial/superglazka/

В репозитории нет файла `CNAME`: отдельные домены не должны перехватывать адрес `github.io`, пока вы сами этого не захотите.

### Как включить, если Pages ещё выключены

Нужен публичный репозиторий. Источник — **GitHub Actions**, публикация с ветки `main`.

1. Откройте **Settings → Pages**.
2. В **Build and deployment** поставьте **Source: GitHub Actions**.
3. Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) сам запускается при пуше в `main` и по кнопке **Run workflow**. Он выкладывает корень сайта: хаб, `superglazka/` и `fond/`.
4. Когда прогон станет зелёным, адрес появится на вкладке Pages и в окружении `github-pages`.

Файл `.nojekyll` уже лежит в корне. Если вместо Actions выбрать **Deploy from a branch → main → / (root)**, хаб и обе папки тоже откроются. Предпочтительный способ — Actions из этого workflow.

## Что сознательно не выдумано

- Нет сумм сбора, кроме примера `0 / [цель]`.
- Нет имён команды и нет цитат, подписанных людьми.
- Нет обещания, что сериал лечит зрение. Есть формулировка: сериал не является медицинским изделием и не заменяет консультацию врача. Если зрителю меньше 14 лет — нужны родители.
- Список из 9 глав и число роликов взяты со страницы https://superglazka.ru/watch на 4 ноября 2026 года.
- Цифры фонда (более 2 000 000 ₽, 53 коляски, 653 очков, 12 156 диагностик, 3 695 осмотров) стоят с пометкой «по данным сайта фонда»: https://bf-vidial.bitrix24site.ru/
